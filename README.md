# SobiRun

**SobiRun is an endless running game inspired by Google's Dino Chrome. We built this as our semester project.**

---

## Setup with git

1. Make sure you already install python in your Laptop or Pc <br>
   Open your Command Prompt or Terminal, type "py --version". <br>
   if you already install python there's should be text that tells you what version are you using <br>

   > _example picture_

2. Clone this project <br>
   Click "Code" button and copy the link.
3. Open Visual Studio Code or any code editor <br>
   Open the terminal in your code editor, then type "git clone link.
4. Install pygame (if you're using latest python version use pygame-ce)
5. Click run button on your top right screen or you can run this game by clicking Run > Run without debugging

   if you already install python there's should be text that tells you what version are you using <br>

   > _example picture_

2. Download the project <br>
